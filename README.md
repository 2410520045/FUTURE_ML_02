# Support Ticket Classification

## How to run

```bash
pip install pandas numpy scikit-learn matplotlib openpyxl jupyter
python support_ticket_classification.py
```

Or open `Support_Ticket_Classification.ipynb` in Jupyter Notebook.

## Files

- `support_tickets.csv` - dataset
- `support_ticket_classification.py` - complete Python code
- `Support_Ticket_Classification.ipynb` - notebook
- `Support_Ticket_Classification_Project.xlsx` - Excel workbook
- `Project_Report.txt` - project report
- `sample_predictions.csv` - example predictions
- PNG files - project visualizations

## Method

TF-IDF converts ticket text into numerical features, and Logistic Regression performs the category and priority classification.
